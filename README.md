# MonoMono

Simple stereo to mono audio conversion tool for Windows and Mac.

# Basic Usage

1. Drag and drop a stereo audio file from file explorer / Finder OR straight from your DAW into MonoMono
2. Click Convert to mono
3. A mono version is created on the same folder as the original audio ending in "_MonoMono"

You can then delete the original (Multi-mono) file, or keep it. Its up to you.

## Bath rename proceed files

You may want to rename the files to remove the "_MonoMono" ending. To do this you can:

(on PC)

* Download and install "[Microsoft PowerToys](https://apps.microsoft.com/detail/xp89dcgq3k6vld)"
* Open PowerToys
* In the Dashboard enable "PowerRename"
* Select file(s) on file explorer
* Right click
* Choose "Rename with PowerRename"
* On the "Search For" text box type or copy paste this: *_MonoMono*
* On "Replace With" type an empty space
* Click Apply, done!

(on Mac)

* Select file(s) on finder
* click the tree dots (top right)
* Choose "Rename"
* Select "find and replace" from the top-most drop down menu
* On "find" type or copy paste this: *_MonoMono*
* On "replace" type an empty space
* Click Raname, done!
